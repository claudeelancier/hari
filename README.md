# Sri Murugan Travel — cinematic hero

Premium homepage hero for [Sri Murugan Travel Agency](https://www.srimurugantravel.com/), using the agency’s own destination photography.

Motion language (from the six premium UI animation patterns):

1. Split-character headline reveal
2. Clip-path image unfold
3. Magnetic call-to-action
4. Hover image scale + caption
5. Infinite destination marquee
6. Custom cursor with destination labels

## Preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

Then visit http://localhost:4173
