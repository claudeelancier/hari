# Sri Murugan Travel — Living Kolam Hero

Standalone homepage hero for [Sri Murugan Travel Agency](https://www.srimurugantravel.com/).

The courtyard animation is a **sikku kolam**: pulli (rice dots) are placed first, then a single unbroken loop of rice-flour grains weaves around them. Destinations sit on the kolam as vermillion bindis. Hover a bindi to iris-develop that journey in the oracle lens. Pointer position also shifts the dawn light (pre-dawn indigo to noon gold).
