# Sri Murugan Travel — cinematic hero

Standalone, drop-in **hero section only** for [srimurugantravel.com](https://www.srimurugantravel.com/).

## Preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Integrate

Copy `index.html` hero markup plus `assets/hero.css` and `assets/hero.js` into the live homepage in place of the current banner slider.
