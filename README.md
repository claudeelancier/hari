# Elancier Solutions

Premium 2026 website for Elancier Solutions — a Madurai web, mobile and digital product studio.

## Stack

- Next.js 14 (App Router)
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- TypeScript

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Factual company, client, project and contact details are sourced from the public Elancier website. Testimonials are not fabricated; the client-experience section is marked for verified quotes.
