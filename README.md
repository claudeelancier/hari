# Nuvora

Original multi-page SaaS marketing site inspired by the visual structure of premium software landing templates.

Open `index.html` in a browser or use a local static server. No build step is required.

## Stack

- HTML5, CSS3, vanilla JavaScript
- Bootstrap 5 grid CSS
- Swiper.js
- Bootstrap Icons
- Google Font: Rubik

## Pages

Home, about, features, integrations, pricing, projects, blog, auth layouts, legal, and 404.
