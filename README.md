# Elancier Solutions website

PHP multi-page site for Elancier Solutions (Madurai).

The 2026 visual system lives in `css/elancier-2026.css` and `js/elancier-2026.js`, included from `partials/header.php` and `partials/footer.php`.

Host by uploading this folder to the web root. PHP mail is required for `php/form-process.php`.
